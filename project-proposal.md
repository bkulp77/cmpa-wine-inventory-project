# Project Proposal: Personal Wine Inventory and Descriptions

## 1. Project Description

### What is it?

I often struggle to remember what wines I have in my collection, we belong to several wine clubs in both Washington State and Texas and have a collection of around 200 bottles. I have used Excel trackers in the past but they aren't easy to look at and don't provide much information.  I would like to build a site that will allow me an my wife to track our wine and see descriptions of the wine and have links to those wineries so we can order more.

### Why does it matter?

Wine is more than a beverage it is an experience and to have all the information about the wine in one place will enhance the experience. A good wine tracking website will help with drinking older wine before it goes bad and helping with inventory management when we are low on our favorite wine.

### Who is it for?

The intended audience is for the casual home wine enthusiast that doesn't want to use expensive wine tracking software but doesn't want to just depend on an excel spreadsheet that won't have much information. 

## 2. Feature Plan

### Project 1

* **Inventory Dashboard**: A landing page that displays the overall bottle count and a bottle count by type, vintage or winery.

* **Filterable Wine Catalog**: A catalog grid showing all entered wine that is filterable by any category

* **Bottle Images**: All bottle images will be uploaded and part of the inventory. When you hover on the bottle it will pop out to a much larger image to be able to read the label.

### Project 2

* **Supabase Database conversion**: Change the inventory database from a local file in my project folder to one online so that I can add buttons for increasing or decreasing quantity to the website.

* **Wine Region Descriptions**: A page for Texas, California, and Washington State wines with descriptions of the regions of bottles in the inventory.
