# Reflections
## Decisions
The most important decision of this project was what can I build that will help solve a problem I have and maybe be useful to other people.  My spreadsheet for my wine inventory would get updated periodically and then I would stop updating and have to start over because it would be completely out of date.  My wife would also drink or buy wine when I travel and those wouldn’t get updated either.  I decided that this project would be a perfect way to make a website which turned into an iOS app much easier for us to keep track of our wine. The other important decisions were what features to have in it so that it was complete but not overly complicated and cluttered.
## What worked
I think the final project everything worked very well. The only thing that didn’t as well as I liked was the speed at which the website loads.  I have some issues initially where it did load quickly but it wouldn’t update the inventory from the online Supabase file for up to an hour. I had issues with my computer or phone loading a cached version on the site so my numbers weren’t in real time and when I fixed that it made the site load slower. It took many iterations to get the site to where it is now.
## What I would do differently
I would have tried to get google sheets or another online database for the project.  The free version of Supabase will freeze a project after 7 days of inactivity. I’m looking at transitioning to a shared iCloud database of this for our personal use of this for future use.
## What I learned
The biggest thing I learned from this is AI is far from perfect, while it did help with some features that I didn’t know how to add, it did give me wrong or incomplete information a lot of the time but It did lead me in the right direction.  I learned that once I have something that works it doesn’t take much to tweak it to use for something completely different. I plan on using the bones of this site for other inventory trackers.  I have never dealt with JavaScript before this project so that was a big learning curve, I also learned that making one minor change can break everything and then spend hours trying to figure out what broke it. While not in the scope of the turned in project I also learned about Xcode and Capacitor in trying to convert this to an iOS app, I turned it into Apple yesterday and already got it approved for external test flight testing. I have also learned that I really like doing this and it’s driving my wife crazy that I keep sitting at the computer working on this. When I retire from my Navy job I could see myself doing this kind of work for some extra money, I know I still have a lot more to learn but I’m enjoying it.
