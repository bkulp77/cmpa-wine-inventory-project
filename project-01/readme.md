# My Wine Inventory

This project is a website that will allow me to track my extensive personal wine inventory and have links and descriptions of our favorite wineries while also tracking the bottles we have to ensure we drink them before they go bad. With this my wife and I would both be able to update the inventory from either of our phones and a central database will be updated so we always have an accurate inventory.  

Excel spreadsheets in the past don't get updated and aren't visually appealing so having a website with buttons to increase and decrease quantities will make it much easier to track.
One paragraph describing what the project is and does. In version 2 for the final project I would like to include a form for entering new wines and a shared database hosted by Supabase so that the inventory is actually updated from the website and not just the local csv file.


## Purpose

The purpose of this website is to track the wines we have and be able to enjoy them before they get too old.  It will also allow us to see remotely when we need to get more and what kind of wine we need.
